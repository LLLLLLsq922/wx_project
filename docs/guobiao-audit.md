# 国标规则审计记录

## 基准

审计基准采用世界麻将组织《麻将竞赛规则》2014/2021版：

- [世界麻将组织中文版规则](https://www.mindmahjong.com/adobe/z20140402.pdf)
- [世界麻将组织2021版规则](https://www.mindmahjong.com/adobe/ZC2021.pdf)

项目保持用户确认的136张无花牌设定。因此标准81项中移除“花牌”，代码目录应包含其余80项。起和仍要求非花牌番种合计至少8分。

## 已确认并修复的问题

1. 原目录和引擎只有78项，缺少“七星不靠”和“全双刻”。现已补齐定义、识别和不计关系。
2. 原“全不靠”要求七种字牌全部出现，实质上混淆了七星不靠，同时只用“无同花色三连”判断数牌。现改为从固定花色的147、258、369九张骨架与七种字牌共16张中选择14张不同单张。
3. 原组合龙允许147、258、369在三门之间错位。现要求三组分别固定为不同花色。
4. 平和现按“四副顺子加序数牌将”判断，允许副露以及含幺九的顺子，并只排除无字；可以与断幺叠加。
5. 暗杠与双暗杠分别修正为2分和8分；双暗杠会排除暗杠、双暗刻。
6. 荣和牌仅用于完成刻子时，该刻子不再误计暗刻；自摸完成的刻子仍可计暗刻。
7. 边张、坎张、单钓将增加唯一听牌校验；同一手牌存在其他可和牌时不计等待分。
8. 连六、老少副、幺九刻、一般高、喜相逢、双同刻支持按互不复用的组合重复计分。
9. 一色三步高和一色四步高同时支持递增1或递增2；全带五会校验将牌也含5。
10. 不求人允许暗杠；全求人要求四副均为明露且必须荣和。碰碰和可与断幺、双同刻、双暗刻叠加。
11. 妙手回春、杠上开花不再重复计自摸；抢杠和不再重复计和绝张，并在适配器入口校验自摸/荣和情境冲突。
12. 推不倒的牌张集合修正为1234589筒、245689条和白板；花龙移除了规则未规定的不计项。
13. 按2021版规则正文重新核对高番至6番番种的不计关系，移除绿一色、清龙、一色三步高、三杠等项目中原先过度排除的可叠加番种。
14. 四杠只排除单钓将，三杠不再吞掉杠牌加计；暗杠、双暗杠、明杠、双明杠可按实际组合继续计分。
15. 一色双龙会改为直接检查四副顺子和五作将，允许通过吃牌形成，不再错误要求门前状态。
16. 清一色明确要求一种数牌花色，避免纯字牌被同时误判为清一色。
17. 清幺九、混幺九、全带幺增加标准“四副面子加将牌”结构约束，避免十三幺等特殊结构串算；十三幺、七对自摸统一按不求人计分。
18. 七对允许一组四张同牌作为两对，分析结果会保留四张实体牌，因此可以正确加计四归一。
19. 组合龙改为先提取固定花色的147、258、369九张骨架，再校验剩余面子与将牌；支持字牌刻子以及一副吃、碰或杠，并可继续识别箭刻、五门齐、平和等叠加番种。
20. 特殊结构与标准结构不再提前二选一，而是进入同一评分候选集合；按最终总分选择最佳拆法，并向统一接口返回去重后的其他候选和未采用原因。
21. 按不拆移与不重复原则补齐组合级排除：四杠不重复计三杠、碰碰和，清龙不复用自身三副顺子计连六、老少副，三色三同顺不计喜相逢，三同刻不计双同刻。
22. 统一输入适配器现支持顶层规范 `winTile`，并在计算前校验和牌张必须存在于暗手、圈风/门风索引必须在0至3之间；吃、碰、杠同时校验实际牌张能否组成对应副露。
23. 听牌分析只返回最终达到国标至少8分门槛的合法和牌，并根据手牌、副露及可见牌扣减余量；某牌四张均已知时不再显示为可用等待。
24. 杠牌组合按2021版规则校准：两明杠计4分，一明杠加一暗杠计6分；三杠、四杠不再重复追加其中的单明杠或双明杠，暗杠仍按规则加计。
25. 修正全带五的不计关系，只排除断幺并允许加计无字；三色双龙会的不计项与官方正文统一为平和、无字、喜相逢、老少副。
26. 补齐全部80个非花牌番种的自动化正例、负例及不计关系矩阵，并修正小四喜、推不倒、双箭刻、边张、坎张、单钓将等规则百科牌例。

## 审计结论

在136张无花牌范围内，80个番种的目录、番值、成立正例、不成立负例、声明的不计关系和主要复合边界已完成逐项审计。覆盖矩阵见 `docs/guobiao-coverage.md`，测试会将实际命中集合与规则目录逐项比较，后续增加、删除或改名番种时不得留下未覆盖项。

规则层审计已完成不代表微信真机验收完成。页面触摸、音效、震动、分包首次加载和不同尺寸设备布局仍需在阶段一结束前执行一次真机回归。

- 重复连六、幺九刻、一般高、喜相逢、双同刻的累计。
- 暗杠、双暗杠以及末张、杠后、抢杠事件番的分值与排除关系。
- 绿一色叠加清一色与断幺、一色双龙会副露、三杠和四杠加计。
- 字一色与清一色互斥、十三幺不串算混幺九和全带幺。
- 七对包含四归一、组合龙带字牌刻子或一副副露。
- 七对与标准结构并存时选择最高分拆法并保留其他候选。
- 清龙、三色三同顺、三同刻和四杠的组合级不重复计分。
- 第五张同牌、杠后结构与实际牌数。
- 和牌张、风位索引与吃碰杠实际组成的输入边界。
- 听牌结果的8分门槛、可见牌余量和四张耗尽过滤。
- 全部80个非花牌番种均有自动化正例和负例，目录、不计关系及规则百科保持一致。
- 两明杠、一明一暗、双暗杠、三杠和四杠的组合计分边界。

后续对国标规则的任何修改都必须同步更新覆盖矩阵，并保持矩阵测试无空项。
