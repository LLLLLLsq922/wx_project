# 第一、二阶段外部验收测试手册

版本：1.0  
基准分支：`feat/sichuan-phase2-engine`  
基准提交：`9791861`  
适用范围：第一阶段共享基础与国标麻将、第二阶段成都川麻  
执行方式：微信开发者工具编译检查 + 手机真机人工测试

## 1. 测试目标与边界

本手册用于验证自动测试无法完全覆盖的微信运行时、手机显示、触控反馈、本地存储及完整牌局操作流程。

以下内容不属于第一、二阶段，当前没有入口或尚不能使用时不算本轮缺陷：

- 四人日麻算牌与牌局结算。
- 国标麻将整场牌局管理。
- 跨玩法统一历史筛选、历史局修改、撤销和重算。
- 分数走势图、单局结算图、整场战绩图、保存相册及微信分享。
- 用户可见的声音/震动设置页。
- 云端同步、账号登录、跨设备恢复。

牌型算法、番种不计关系、总分守恒和数据迁移已有自动化测试。本手册仍保留关键牌例的界面抽查，用于确认输入、显示和跳转链路没有接错。

## 2. 验收规则

优先级说明：

- `P0`：阻断发布。编译失败、崩溃、数据损坏、非法和牌可入账、分数不守恒等。
- `P1`：发布前必须修复。主要流程不可用、页面严重错位、草稿无法恢复等。
- `P2`：体验问题。轻微排版、文案、动画或声音问题。

每个用例执行后勾选一项，并在失败时记录实际表现：

```text
[ ] 通过  [ ] 失败  [ ] 阻塞  [ ] 不适用
实际结果：
截图/录屏：
设备与系统：
备注：
```

通过标准：

1. 所有 `P0`、`P1` 用例通过。
2. `P2` 问题有明确记录，不存在严重影响手机使用的布局问题。
3. 任意一局每次结算后，四家分数变化之和均为0。
4. 微信开发者工具没有编译错误、页面路径错误或资源加载错误。
